# Проект предсказания цен автомобилей

Этот проект представляет собой решение задачи регрессии для предсказания стоимости автомобилей на основе датасета Autos. Модель анализирует различные характеристики транспортных средств для определения их рыночной стоимости.

## В рамках проекта:
- Проведен анализ и предобработка данных о характеристиках автомобилей
- Построены различные модели машинного обучения (Linear Model, Decision Tree, Random Forest, XGBoost, CatBoost)
- Рассчитаны метрики качества моделей: коэффициент детерминации (R²), среднеквадратичная ошибка (MSE) и корень из среднеквадратичной ошибки (RMSE)

## Результаты:
Серия экспериментов с различными алгоритмами машинного обучения показала, что XGBoost превосходит конкурирующие модели, достигая коэффициента детерминации R² = 0.89.
